# Principles

Read a principle with `aep --skill principles --ref ID`. Add `--attempt ATTEMPT_ID` to retain a local read receipt for runbook validation.

- `prove-it`: Judge completion by the actual candidate and observed output.
- `encode-lessons`: Turn the recurring failure into a rule, check or guard with supporting evidence.
- `verifiable-units`: Give each unit an observable completion condition and check dependencies before starting dependent work.
- `respond-in-their-terms`: Explain the user impact. For a decision, give options with tradeoffs and a recommendation with its reason.
