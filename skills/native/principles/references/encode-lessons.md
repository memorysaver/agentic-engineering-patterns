# encode-lessons

**Trigger.** When the same correction recurs.

**Rule.** Turn the recurring failure into a rule, check or guard with supporting evidence.

**Enforcement.** Use the existing lesson and rule lifecycle; adoption and evaluation retain evidence. Choosing an effective guard remains agent judgment.

**Evidence basis.** Adopted as general engineering guidance for AEP 5.0. The release tests exercise the catalog and citation checks; they do not establish downstream occurrences of this principle. Project-specific observations belong in the project lesson store.
