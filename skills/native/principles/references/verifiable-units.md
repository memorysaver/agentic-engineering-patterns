# verifiable-units

**Trigger.** When work spans multiple stories or concurrent attempts.

**Rule.** Give each unit an observable completion condition and check dependencies before starting dependent work.

**Enforcement.** Dispatch checks dependencies and verification binds results to the candidate. Story decomposition remains agent judgment.

**Evidence basis.** Adopted as general engineering guidance for AEP 5.0. The release tests exercise the catalog and citation checks; they do not establish downstream occurrences of this principle. Project-specific observations belong in the project lesson store.
